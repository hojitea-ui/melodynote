MELODYNOTE SEC 01 / INPUT ○ SERVER …

녹음한 멜로디를 악보로

피아노 양손이나 허밍으로 녹음한 모티브에서 멜로디를 골라 오선지에 그리고, 고쳐서 MIDI로 내보냅니다.

01

입력

녹음 종류

00:00 / 01:00 마이크 대기

녹음은 1분이 되면 저절로 멈춰요.

입력
-
길이
-
원본 형식
-
보낸 형식
-

어떤 녹음이 되나요

양손·반주
피아노처럼 여러 음이 함께 울리는 녹음. 가장 높은 줄을 멜로디로 골라요.
한 줄
허밍·노래·단선율 악기. 음높이를 그대로 따라가요.
길이·형식
1분 이내. 브라우저 녹음이나 wav, mp3, m4a 파일
처리 위치
이 컴퓨터의 서버. 녹음을 밖으로 보내지 않아요.
02

인식 · 멜로디 · 박자

IDLE
  1. a소리 준비PREPARE

    브라우저가 WAV로 바꿔 보내요

    □ WAITING--
  2. b음 인식PITCH

    AI가 울린 음을 찾아요

    □ WAITING--
  3. c멜로디 고르기SEGMENT

    가장 높은 줄을 멜로디로

    □ WAITING--
  4. d박자 맞추기RHYTHM

    템포·박·조성을 정해요

    □ WAITING--

변환하면 결과 요약이 여기 나옵니다

03

악보 편집

악보는 이 자리에 그려져요

위 01 입력에서 녹음하거나 파일을 올리면, 몇 초 뒤 멜로디가 오선지로 나타나고 편집 도구가 열려요.

열리면 할 수 있는 것

  • 음을 눌러 반음·옥타브·길이 고치기, C~B로 음이름 입력
  • 빠진 음 추가, 박자표·못갖춘마디·템포 맞추기
  • 들어 보기, MIDI 내보내기

음을 눌러 고치세요. ?는 AI가 불확실하다고 표시한 음입니다.

멜로디 최저음보다 낮은 음은 멜로디 후보에서 빠져요. 왼손 음이 섞이면 올리고, 멜로디가 잘리면 내리세요. 템포·최저음을 바꾸면 고친 내용이 사라지니 먼저 맞추세요.
