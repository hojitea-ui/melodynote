# 멜로디노트

녹음한 멜로디(단선율)를 오선지 위의 음으로 바꾸는 웹앱. 기획은 [docs/PRD.md](docs/PRD.md).

## 지금 있는 것 (1단계: 핵심 파이프라인)

음성 파일 → 음높이 인식 → 음 길이 분리 → 박자 보정 → 악보 데이터(JSON) · MIDI

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 음높이 인식 | `pipeline/pitch.py` | librosa pYIN으로 프레임별 음높이, 무음 구간 제거, 전체 음정 치우침 측정 |
| 음 길이 분리 | `pipeline/segment.py` | 음높이 변화·소리 세기의 골로 음을 나눔, 불확실한 음 표시 |
| 박자 보정 | `pipeline/rhythm.py` | 템포 추정, 16분음표 격자에 맞춤, 조성 추정 |
| 출력 | `pipeline/midi_out.py`, `pipeline/transcribe.py` | MIDI 쓰기, PRD 오류 문구 처리, 단계별 처리 시간 기록 |

## 설치와 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```powershell
.\.venv\Scripts\python.exe -m pipeline 녹음.wav -o out
```

템포를 알고 있으면 `--bpm 90`처럼 지정할 수 있다. 결과는 `out/녹음.json`과 `out/녹음.mid`.

JSON의 `status`는 PRD 5장의 오류 대응과 맞춰 두었다.

| status | 뜻 | message |
|---|---|---|
| `ok` | 정상 | 없음 |
| `uncertain` | 불확실한 음이 30% 넘음 (화음·잡음 의심) | 멜로디 하나만 인식할 수 있어요. 불확실한 음은 ?로 표시했어요 |
| `no_notes` | 음을 못 찾음 | 음을 찾지 못했어요. 조용한 곳에서 다시 녹음해 주세요 |
| `too_long` | 1분 초과 | 1분 이내 녹음만 변환할 수 있어요 |

음마다 `uncertain`과 `reason`(`weak_voicing`, `between_pitches`, `unstable_pitch`, `missing_fundamental`)이 붙는다.

## 합성 멜로디 점검

```powershell
.\.venv\Scripts\python.exe -m eval.synth_check
```

정답을 아는 멜로디를 합성해 넣고 잰 결과 (Windows 노트북, 2026-11-27):

| 경우 | 길이 | 음높이 정확도 | 음가 한 단계 이내 | 템포 추정/실제 | 처리 시간 |
|---|---|---|---|---|---|
| 순음 | 15s | 100% | 100% | 98/100 | 6.4s (첫 실행 포함) |
| 배음 있는 소리 | 15s | 100% | 100% | 98/100 | 1.8s |
| 노래 흉내 (비브라토·꺾임·음정 치우침·박자 흔들림) | 17s | 100% | 100% | 90/92 | 3.4s |
| 위 + 잡음 (SNR 20dB) | 17s | 100% | 100% | 94/92 | 2.2s |
| 빠른 스타카토 | 11s | 100% | 100% | 71/140 (절반) | 1.3s |
| 1분 무작위 멜로디 | 60s | 97% | 95% | 100/100 | 9.2s |

- 무음과 백색잡음은 `no_notes`, A·C#·E 화음은 `uncertain`으로 처리된다.
- 1분 녹음을 새 프로세스에서 처음 돌려도 11.5초 걸렸다. 처음 실행할 때는 numba 컴파일 때문에 몇 초가 더 든다. 서버로 만들 때는 시작할 때 한 번 미리 돌려 두면 된다.

**주의:** 합성음이라 실제 녹음보다 쉽다. 이 숫자는 파이프라인이 제대로 도는지 확인하는 용도다. PRD 성공 기준은 실제 녹음과 직접 채보한 정답 곡으로 다시 재야 한다 (2단계).

## 알려진 한계

- 템포가 2배나 절반으로 잡힐 수 있다. 악보 표기만 달라지고 음의 순서·길이 비율은 같다. 화면에서 고칠 수 있게 할 예정.
- 박자표는 4/4로 고정이다. 못갖춘마디는 처리하지 않는다 (첫 음을 첫 박에 둔다).
- 같은 음을 레가토로 이어 부르면, 소리 세기의 골이 5dB보다 얕을 때 한 음으로 합쳐진다.
- 화음 감지는 '기본음이 비어 있는지'만 본다. 기본음이 실제로 울리는 화음은 놓칠 수 있다.
